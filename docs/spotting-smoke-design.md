# 点亮系统与烟雾弹设计文档

## 1. 点亮系统

### 1.1 核心概念

每台坦克有三种可见状态：

| 状态 | 小地图 | HUD 敌标 | AI 行为 |
|------|--------|---------|---------|
| **未发现** | 不显示 | 不显示 | 巡逻/待命 |
| **点亮** | 红色三角（实时位置/朝向） | 血条 + 距离 | 交战（追击 + 开火） |
| **失联** | 灰色三角（最后位置，不更新） | 灰色 ? 标记 | 搜索（向最后位置移动） |

### 1.2 状态流转

```
未发现 ──视线命中──→ 发现中(0.5s) ──→ 点亮（实时更新位置/朝向）
点亮 ──失去视线──→ 点亮保持(3s) ──→ 失联(7s) ──→ 未发现
失联 ──重新视线命中──→ 点亮
```

- **点亮保持**：失去视线后仍显示 3 秒（模拟信息传递延迟）
- **失联**：3 秒后进入失联，显示最后已知位置（灰色），持续 7 秒后完全消失
- **失联中重新发现**：直接回到点亮状态

### 1.3 视线检测（Line of Sight）

从车长塔位置向目标车长塔位置发射检测线，三种遮挡源：

#### 地形遮挡

复用现有 `terrainHeight(x, z)` 步进采样：

```
for (d = 0; d < dist; d += step) {
  point = lerp(eyeA, eyeB, d / dist)
  if (terrainHeight(point.x, point.z) > point.y) → 遮挡
}
```

- 步长 4m，检测距离上限 600m
- 每次最多 150 次采样（纯 sin/cos 运算）

#### 障碍物遮挡

遍历 `world.obstacles`，检查障碍物圆心到视线的距离：

```
for (obs of nearbyObstacles) {
  if (pointToSegmentDist(obs, eyeA, eyeB) < obs.r) → 遮挡
}
```

- 仅检查视线段附近的障碍物（距离预筛）

#### 烟雾云遮挡

检查视线是否穿过任何活跃烟雾云：

```
for (smoke of activeSmokes) {
  if (segmentIntersectsSphere(eyeA, eyeB, smoke.pos, smoke.r)) → 遮挡
}
```

### 1.4 观察参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 观察距离 | 600m | 超过此距离不点亮 |
| 车长塔视野 | 360° 全向 | 车长塔可全周观察 |
| 发现延迟 | 0.5s | 视线命中后延迟 0.5s 才点亮（模拟车长识别时间） |
| 检测频率 | 每 0.3s 一次 | 非每帧检测 |
| 点亮保持 | 3s | 失去视线后仍可见 |
| 失联持续 | 7s | 失联后显示最后位置 |

### 1.5 暴露机制

| 事件 | 效果 |
|------|------|
| **开火** | 自动被所有 800m 内敌方点亮 3 秒（炮口火光/声音暴露） |
| **移动** | 被点亮距离 +100m（引擎/履带噪音，尘土） |
| **静止** | 正常观察距离 |

### 1.6 双向点亮

- **玩家点亮敌方**：玩家车长塔检测 → 敌方在小地图/HUD 显示
- **敌方点亮玩家**：敌方车长塔检测 → AI 进入交战
- **代理点亮**：被队友点亮的敌方，队友共享给你（生存模式多敌场景适用）

### 1.7 性能保障

| 措施 | 说明 |
|------|------|
| 低频检测 | 每 0.3s 一次，非每帧 |
| 距离预筛 | 超过 600m 直接跳过 |
| 分帧分散 | N 对检测分散到 N 帧执行 |
| 地形步进 | 纯数学函数，无 Raycaster |
| 障碍物预筛 | 仅检查视线段附近的障碍物 |

## 2. 烟雾弹系统

### 2.1 概述

烟雾弹用于遮蔽视线，阻断敌方观察。发射后在落点生成一片持续烟雾云，云内坦克不会被点亮，穿过烟雾云的视线被阻断。

### 2.2 发射操作

| 按键 | 动作 |
|------|------|
| **G** | 发射烟雾弹（炮塔前方 120° 扇形，抛射到空中后落下成烟） |
| **G 长按** | 连续发射（间隔 1.5s，至弹尽） |

- **发射基准**：以火炮炮口位置为起点
- **发射方向**：炮塔指向正前方 ±60°（120° 扇形内随机）
- **弹道**：抛物线，发射到空中（初速约 30m/s，仰角 60°），飞行约 2 秒后落地
- **落点**：距炮口约 30~50m，落地后 1 秒烟雾云完全展开
- **AI 发射**：AI 有 <20% 概率使用烟雾弹（条件：被点亮且血量 <40% 时触发判定）

### 2.3 烟雾弹参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 携带数量 | 5 发 | 每场战斗初始 |
| 发射间隔 | 1.5s | 连续发射冷却 |
| 烟雾云半径 | 18m | 完全展开后 |
| 展开时间 | 1s | 从 0 渐变到满半径 |
| 持续时间 | 18s | 满半径后开始消散 |
| 消散时间 | 3s | 半径渐缩至 0 |
| 总寿命 | ~22s | 展开 + 持续 + 消散 |

### 2.4 烟雾云生命周期

```
发射 → [0~1s] 展开（半径 0→18m，渐变透明度）
     → [1~19s] 持续（满半径 18m，稳定）
     → [19~22s] 消散（半径 18→0，透明度渐增）
     → 移除
```

### 2.5 视线遮挡

烟雾云作为球形遮挡体参与视线检测：

- **展开中/持续中**：视线穿过烟雾球 → `canSee = false`
- **消散中**：遮挡概率随消散进度递减（`遮挡概率 = 1 - 消散进度`）
- **多个烟雾云**：任一遮挡即阻断视线

### 2.6 烟雾云内效果

| 对象 | 效果 |
|------|------|
| 云内坦克 | 不会被云外坦克点亮（出云后恢复） |
| 云外坦克 | 无法点亮云内坦克 |
| 云内坦克之间 | 正常互相点亮（距离 < 烟雾半径时） |
| 炮弹 | 不受影响（物理弹道正常飞行） |
| 开火暴露 | 仍然有效（开火被 800m 内敌方点亮） |

### 2.7 视觉渲染

烟雾云用粒子系统渲染：

- **粒子数量**：每团烟雾 30~50 个粒子
- **粒子形态**：软边缘圆形 sprite（billboard），半透明灰白色
- **动画**：粒子缓慢上升 + 水平漂移 + 大小渐变
- **颜色**：浅灰白 `rgba(200, 200, 195, 0.3~0.6)`
- **展开阶段**：粒子从中心向外扩散
- **消散阶段**：粒子透明度渐增至消失

### 2.8 HUD 显示

- **烟雾弹计数**：右下角速度面板下方显示 `SMK ×3`（剩余数量）
- **发射冷却**：冷却中显示灰色倒计时
- **烟雾弹耗尽**：显示 `SMK EMPTY`

## 3. 技术实现方案

### 3.1 新增/修改文件

| `js/visibility.js` | **新建** | VisibilityManager：视线检测 + 点亮状态管理 |
| `js/smoke.js` | **新建** | SmokeManager：烟雾弹发射 + 烟雾云生命周期 + 渲染 |
| `js/tank.js` | 改 | 加 `spotted`/`spotTimer`/`lastKnownPos`/`smokes` 字段 |
| `js/ai.js` | 改 | 未点亮时巡逻，点亮时交战，失联时搜索 |
| `js/minimap.js` | 改 | 仅绘制 spotted 敌方，失联用灰色最后位置 |
| `js/ui.js` | 改 | 仅显示 spotted 敌标，加烟雾弹计数 HUD |
| `js/main.js` | 改 | 主循环调 visibility/smoke update，G 键发射烟雾 |
| `js/effects.js` | 改 | 加烟雾粒子系统 |

### 3.2 VisibilityManager 接口

```js
class VisibilityManager {
  constructor(world, obstacles)
  update(dt, tanks)           // 每 0.3s 检测所有坦克对的视线
  canSee(a, b)                // a 能否看到 b（地形+障碍+烟雾遮挡）
  isSmokeBlocked(a, b)        // 烟雾云是否遮挡 a→b 视线
  setSmokeManager(smoke)      // 注入烟雾管理器
}
```

### 3.3 SmokeManager 接口

```js
class SmokeManager {
  constructor(scene, effects)
  fire(tank)                  // 坦克发射烟雾弹
  update(dt)                  // 更新所有烟雾云生命周期
  isBlocked(a, b)             // a→b 视线是否被烟雾遮挡
  getActive()                 // 获取活跃烟雾云列表
  dispose()
}
```

### 3.4 烟雾云数据结构

```js
{
  pos: Vector3,       // 烟雾中心位置
  r: 0,               // 当前半径（渐变）
  rMax: 18,           // 最大半径
  age: 0,             // 存活时间
  lifetime: 22,       // 总寿命
  phase: 'expand',    // expand → sustain → dissipate
  particles: [],      // 粒子数组
}
```

### 3.5 集成到主循环

```js
// main.js _frame()
if (this.state === 'battle') {
  this.visibility.update(dt, [this.player, ...this.enemies]);
  this.smoke.update(dt);
  // ... 其余战斗更新
}
```

### 3.6 集成到 AI

```js
// ai.js update()
if (!player.spottedByMe) {
  // 未点亮：巡逻或向最后已知位置搜索
  this.state = 'patrol';
  return;
}
// 已点亮：正常交战
this.state = 'engage';
// ... 现有交战逻辑
```

### 3.7 集成到小地图/HUD

```js
// minimap.js
for (const e of enemies) {
  if (e.destroyed) continue;
  if (e.spotted) → 绘制红色三角（实时位置）
  else if (e.lostContact) → 绘制灰色三角（最后位置）
  // else: 不绘制
}

// ui.js updateMarkers
for (const e of enemies) {
  if (!e.spotted && !e.lostContact) → 隐藏标记
}
```

## 4. 已确认决策

1. **烟雾弹发射方向**：以火炮位置为基准，炮塔指向正前方 120° 扇形，抛射到空中后落下成烟 ✅
2. **AI 使用烟雾弹**：有放烟能力，使用几率 <20%（条件：被点亮且血量 <40% 时触发判定） ✅
3. **发现延迟**：0.5s 视线命中后延迟点亮（模拟车长识别时间） ✅
