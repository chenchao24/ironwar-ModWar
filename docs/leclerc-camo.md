# 勒克莱尔 S2 迷彩涂装 — 实施记录

> 2026-09-07 · 复用 KF51 建立的程序化迷彩系统（js/camo.js）。初版「法系四色圆斑」经用户指认有误，同日按 TIGER MODEL 1/35 板件涂装指引返工为**北约三色圆缘迷彩**，当前版本以下文第二节为准。

## 一、（已废弃）初版：法系 CE 四色

底色橄榄绿 `#6f7c49` + 黑/棕/深绿小碎斑。问题：色相整体偏黄偏暗（把北约绿做成了黄橄榄、把北约黑做成了绿炭黑），斑块尺度过小且孤立，不符合北约迷彩「大块圆润连片」的形态特征。

## 二、（现行）北约三色圆缘迷彩

**形态与配色基准（第 3 轮）**：用户提供的参考模型 `amx-56_leclrec_main_battle_tank.glb`（Sketchfab，带烘焙贴图）+ TIGER MODEL 1/35 板件涂装指引。

**关于参考模型贴图能否直接用：否。** 该图集（2048²）为 UV 摆放图集而非无缝瓦片，且烘焙极暗（全图中位亮度 22/255，绿色块原始值 ≈#232913，含格栅/车灯/阴影细节）——直接平铺会采样到黑色细节区，且贴到本项目模型的不同 UV 上图案随机错乱。采用「完全参考」：同灯光并排渲染两车、区域聚类采样对齐色彩关系。

| 角色 | 游戏采用值 | 说明 |
|---|---|---|
| 底色 | `#57683e`（黄橄榄绿） | 较指引色标采样值提饱和、对齐参考模型渲染观感 |
| 斑块1 | `#7d5c40`（棕褐） | 从偏橙 #9c6242 收敛（参考模型棕无橙相） |
| 斑块2 | `#383730`（暖调近黑） | 去蓝相 |
| 覆盖率 | 绿 ≈57% / 棕 22% / 黑 21% | 参考模型绿底占比更大 |

色标采样方法：参考图放大裁剪 + 10px 网格标注定位色块中心，7×7/9×9 中位色提取；084/046 曾多次打偏（视口缩放/坐标换算），最终以网格读数定位。

**形式**（`blob` 风格生成器，第 2 版，改用噪声场分带）：
- **生成原理**：多倍频包裹值噪声场（主倍频格跨 260×235px + 二/三倍频细节）按分位数切「深灰/绿底/棕」三带。三色来自同一连续场的低/中/高三段——天然大块连片、互不覆盖、边界为平滑等值线，与豹2A4 烘焙贴图（`model/leopard_2a4.glb` 车体贴图，用户指定形态参照）的拼图咬合特征一致。
- 第一版「印章式叠斑」（随机位置画斑块再互相覆盖）存在两处硬伤：斑块互相压盖产生破碎残边、孤立馒头形团块碎化严重——已废弃；用户中途试验的 `stretchX` 拉伸参数随印章法一并移除，拉伸改由 `fieldCellX/Y` 各向异性表达。
- 无描边；值噪声场天然周期化（取模格点）无缝平铺；种子固定 20260907。
- 可调参数（SCHEMES.leclerc）：`fieldCellX/Y`（斑块基准尺度，主格 260/235px ≈2~3m 斑块；调大更连片、调小更碎）、`fieldOct2/Oct3`（边界波浪与碎湾细节权重）、`dirtVeil`（泥点罩数量）、`uvMeters`（盒式投影世界尺寸）。

**跨部件连续性**（第 3 轮，用户反馈车体侧与炮塔侧图案不连贯）：
- 根源：各部件按自身 UV 各自采样平铺贴图，图案互不相干。
- 方案：`boxProjectUVs()` 三向盒式 UV 重映射——每个三角形按法线主轴选投影面（X→(y,z) / Y→(x,z) / Z→(x,y)），用编著空间世界坐标 ÷ `uvMeters`(10.2m, 1px≈1cm) 重写 UV。全车迷彩件共享同一连续图案场，图案跨车体/裙板/炮塔边界流动（与实车及参考模型一致）；炮塔旋转时图案粘在自身表面（UV 烘在顶点），仅座圈处断开（不可见）。
- 仅作用于迷彩件（else 分支）；履带/素色/哑光件不受影响。

**遮尘片蒙尘**（第 4 轮）：`getRubberDustTexture()` 512² 程序化贴图——深灰黑胶底 + 土黄/土棕尘斑(150 块 α0.08~0.30) + 泥点喷溅(60) + 竖向尘痕(46) + 细颗粒；`rubberDust:true` 启用。

**结构纹路清除**（第 5 轮，用户反馈迷彩上有铆钉/格栅/舱盖轮廓/炮管环纹等"贴图上带的纹路"）：
- 定位：游戏 GLB 的 14 个材质**全部带法线贴图**（素模烘焙的结构浮雕），灯光下以迷彩底色呈现，看起来像迷彩贴图上画了结构线；并非迷彩贴图内容。
- 方案：方案级开关 `clearNormal:true`——迷彩件清除 normalMap/aoMap/lightMap/bumpMap/emissiveMap，表面为纯迷彩。仅 leclerc 启用（KF51 等已认可观感的车不动；KF51 同样全材质带法线贴图，但其浮雕观感未被反馈问题）。
- 试验记录：同轮还试过「暗色独立低频场」加大侧面暗斑连片度 + 去缝线/流挂，用户判定效果不佳已整体回退，维持单场三带与缝线/蒙尘参数。

**鳞片底纹清除**（第 6 轮，用户近距离反馈贴图有"鳞片"状底纹）：
- 定位：逐像素明度抖动（±4）原用乘法哈希 `(x*374761393 + y*668265263) >>> 13 % 9`——线性乘法在 32 位域每 ~11.5 列回绕一次，`>>>13` 截断后呈锯齿波，取模后留下 ~12px 周期的斜向行波，放大观察即"鳞片"。
- 方案：抖动噪声改为滚动 xorshift32 白噪声（种子取 sc.seed，确定性不变），空间无相关，放大后仅为均匀漆面细颗粒。

**暗斑连贯性试验**（第 7 轮，已回退）：用户反馈车体侧的小块暗斑与上缘大块暗斑不连贯，试验「暗色独立各向异性场」（darkCellX 380 / darkCellY 560，V 向=车高方向变化更慢，暗 coverage 0.22）让暗斑沿车高贯通。用户判定不对，已整体回退——现行仍为单场三带（暗色从主场低分位切出，coverage 0.21）。※两次暗色独立场试验（第 5、7 轮）均未通过，后续如再尝试需换思路（如按网格微调 UV 偏移控制特定部件的图案窗口）。

| 处理 | 网格 | 说明 |
|---|---|---|
| 迷彩 | 11/12/13/14（上车体）、26/27 上半（刚性裙板）、17/19（前挡泥板条）、20（动力舱顶甲）、10（翼子板储物箱）、16（炮塔尾篮）、22/23/24/25（炮塔）、15/21/4（炮管/炮闩/炮口制退器） | 板件图炮管带绿/深灰大段迷彩、侧裙带棕斑，均随车体迷彩 |

## 四、验收

- 贴图 2×2 平铺无缝；与豹2A4 烘焙贴图并排对比：同为特大块、圆缘连片、拼图咬合形态，无碎斑；色板与参考模型同灯光并排渲染比对对齐（黄橄榄绿/棕褐/暖近黑）。
- 机库与战斗日光（后 3/4、正侧、6m 近观）核对：图案跨车体/炮塔连续、侧面暗斑连片、炮管分色段；负重轮/履带深色正确；遮尘片深灰黑带土色蒙尘；无结构纹路与鳞片底纹。

## 五、遗留

- 10式（日系双色丛林）、梅卡瓦（西奈灰）复用 `blob`/`pixel` 风格各配 scheme（kf51-panther-design.md §3.5）。
- 再校色：改 `SCHEMES.leclerc` 的 `base`/`layers[].color`；斑块尺度与形态：`fieldCellX/Y`、`fieldOct2/Oct3`；暗斑连贯性两次独立场试验均未通过（见第 7 轮），再尝试需换思路。
