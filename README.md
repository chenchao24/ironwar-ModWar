# 钢铁洪流 IRON WAR — 3D 坦克对战（验证版）

基于 Three.js (WebGL2) 的硬核坦克对战网页游戏。伤害/装甲机制参考《坦克世界》《战争雷霆》。
11 辆现代主战坦克、两张地图、三档 AI 难度；完整防护体系（爆反 / 主动防御 / 观瞄 / 激光压制）与外露子系统毁伤。

## 运行

```bash
npm install        # 已装可跳过（three / puppeteer-core）
npm start          # 启动静态服务器
# 浏览器打开 http://localhost:8080
```

> 必须通过 http 访问（ES Module + GLB 加载限制），双击 index.html 无法运行。

## 操作

| 按键 | 功能 |
|---|---|
| W / S | 前进 / 倒车（油门行程平滑 + 惯性滑行） |
| A / D | 车体转向（高速衰减，倒车镜像） |
| 鼠标 | 观瞄方向（炮塔以自身转速追踪准星），左键开火 |
| Shift / 右键 | 狙击瞄准镜（六国风格密位分划；镜内右键/滚轮变倍） |
| 1 / 2 / 3 | 切换弹种（APFSDS / HEAT / HE） |
| G | 发射烟雾弹（每次 4 发弹体，共 3 次） |
| R / T | 维修包（修模块/观瞄/雷达/压制器）/ 灭火器（每场各 1） |
| N | 热像仪开关（装备车 + 开镜状态，穿透烟雾点亮） |
| M（按住） | 机枪自动射击开关 |
| C | 观赏视角（环绕自由查看），再按返回 |
| 空格 | 制动 |
| Esc | 释放鼠标 / 暂停 |

## 玩法与机制

- **战争模式**：机库选车（11 辆：俄/德/美/英/中，面板附国旗与实车数据）→ 歼灭随机敌方坦克获胜；可选地图（开阔平原 / 东欧小镇）与 AI 难度（新手 / 标准 / 王牌）
- **伤害模型**：分区域装甲（首上/侧面/车尾/炮塔各面，等效 mm RHA）+ 入射角等效换算 + 71° 跳弹角；穿深随距离衰减；击穿后弹芯车内传播判定**弹药殉爆 / 油箱起火 / 发动机 / 座圈 / 履带**
- **防护体系**：爆反装甲（按区剥板，HE 直击多剥 1 块）、APS 主动防御（Trophy 类，拦截窗掷判定、雷达可被扫瞎）、观瞄分级毁伤（散布 ×2/×8）、**激光告警/压制**（99A JD-3 与 T-90 系 Shtora-1：被锁定告警、双向压制致盲、压制器可被机枪打坏）
- **机枪/机炮**：永不伤 HP，只毁外露子系统（剥爆反板 / 伤雷达 / 伤观瞄 / 伤压制器），按口径与距离衰减
- **火控手感**：移动/转向/转炮塔扩圈、静止缩圈（全缩变绿「已瞄准」）；炮塔伺服自带**弹道补偿**（落点压准星）+ **闭环俯仰**（坡地不失准）
- **态势感知**：点亮/失联系统（视线检测 + 烟雾遮断）、小地图、敌标血条/距离；被锁定时有激光告警提示
- **拟真表现**：炮口风暴、殉爆炮塔抛飞、履带印、可破坏建筑、行驶扬尘/排气、起步抬头/急停点头、镜内开火上跳、车库厂房场景（程序化生成，排风扇/浮尘/警灯）

## 结构

```
index.html      入口 + 全部 UI 层（封面/菜单/车库/设置/HUD/狙击镜/结算）
server.js       静态服务器（gzip + 缓存头）
js/             核心代码（22 个模块）
  main.js       主入口：状态机/资源加载/主循环/玩家操控
  config.js     坦克参数（实车数据游戏化）+ 弹种/爆反/APS/传感器/LWS 规则
  tank.js       坦克类：模型拆分/行驶物理/炮塔伺服/命中判定/损伤状态
  garage.js     厂房车库场景（全程序化生成：贴图/灯光/吊臂/氛围）
  ai.js         敌方 AI（难度分级/机动决策/掩体/弱点瞄准/消耗品）
  ui.js         UI：屏幕切换/HUD/车库面板/狙击镜/告警提示
  …             camera / shell / effects / particles / terrain / maps /
                destructibles / smoke / visibility / thermal / trackmarks /
                reticles / minimap / input / tank-display / audio
flags/          5 国国旗 PNG（车库介绍面板）
docs/           设计文档与迭代记录（iteration-summary 系列）
model/ sound/ bgm/   模型（DRACO 压缩）/ 音效 / 背景音乐
```
