## 1. 激光告警/压制系统（LWS）

**车型**：ZTZ-99A（JD-3）、T-90M「突破-3」/ T-90SM「塔吉尔」（Shtora-1 窗帘-1）

- **激光告警**：AI 炮塔锁定玩家期间，罗盘下方 100px 红底白字「⚠ 被激光测距定位」告警框（脉冲光晕），解锁自动消失；
- **激光压制（双向自动，10s 冷却）**：玩家开镜 + 准星命中 + LOS + 目标在射手炮塔 ±110° 扇区内触发——
  我方压制敌 AI：敌 2.5s 停瞄准射击（机动照常），HUD 绿底「激光压制中」倒计时；
  敌方压制玩家：镜内白幕 2.5s×难度系数（新手 0.6/标准 1.0/王牌 1.3），关镜免疫；
- **压制器可打坏**：机枪/机炮扫射分级毁伤（HP 60，损伤档成功率减半），维修包可修，AI 会抢修；保护面板 LWS 行 + 机库参数表行；
- 实测：告警随锁定 1.6s 内自动亮起、双向压制 hitLog 正确、扇区外正确拦截、战斗循环零报错。

## 2. 机库装载体验优化

- **展示车缓存 + LRU（4 台）**：看过的车隐藏常驻，往返秒切（实测 0 帧等待）；
- **分帧纹理预热**：每帧 `initTexture` 4 张 + **邻车预测预热**（预建并预热左右邻），正常浏览节奏下浮标几乎不出现；
- **首次切车分帧装载**：构建→编译→分帧上传→无缝换车，全程页面不冻结，小型浮标（spinner + 进度条）显示进度；
- **面板只刷文字**：参数行池/属性条池 DOM 一次构建，切车仅更新 textContent 与条宽，不再整块重排；
- 开战/结算/回机库全链路无错误，缓存车开战时隐藏保留。

## 3. 车库帧率优化（针对恒定 ~20 FPS）

- **根因**（实测消融定位）：片元开销 = 实时光源数 × 渲染分辨率；几何/阴影/JS 均排除；
- **减灯 + 能量补偿**：实时灯 13 → 8（顶棚 3→1、窗带 2→1、射灯 5→3），半球光 0.62→1.05、环境光 0.45→0.55、窗带/灯管自发光增强——底亮度与亮度感不塌；
- **机库态渲染分辨率 1.0**（战场维持画质档 1.5），开战/回菜单自动恢复；
- **静态阴影**：机库态 `shadowMap.autoUpdate=false`，换车手动刷新，开战恢复动态；
- **亮度探针校验**：平均亮度 82.5 → 82.5（完全一致），暗部 P10 9 → 8 持平；帧耗时（测试机）4.1 → 3.0ms，draw calls 180 → 115，实时灯 −38%。
