## 一、迭代范围概述

本次迭代将 map-test.html 测试图中打磨完成的东欧小镇地图及其配套效果，整合进正式游戏战争模式，并同步升级原有开阔平原地图。核心交付：

1. **可破坏系统模块化**：从 map-test.html 抽取为独立模块 `js/destructibles.js`
2. **多地图管理架构**：新增 `js/maps.js`，重构 `js/terrain.js` 为支持换图的 World 容器
3. **战争模式地图选择**：机库界面可选「开阔平原 / 东欧小镇」，持久化至 localStorage
4. **平原地图升级**：接入同一套可破坏系统（树木倒伏、围栏碾压等）

## 四、发现并修复的缺陷（本次迭代过程中）

| # | 缺陷                                             | 根因                                         | 修复                                                       |
| - | ---------------------------------------------- | ------------------------------------------ | -------------------------------------------------------- |
| 1 | 验证脚本报 import 语法错误                              | .js 未标记模块类型                                | 重命名为 verify\_game\_maps.mjs + createRequire 引入 puppeteer |
| 2 | puppeteer 模块找不到                                | 未装完整包                                      | 改用 puppeteer-core + 指定 Chrome 路径                         |
| 3 | VisibilityManager 空引用 world.obstacles          | 构造时 world 为 null                           | 构造传入 `{ obstacles: [] }` 默认值                             |
| 4 | 模型加载 scene.traverse 报错                         | 布景资产直接使用 GLTF 对象而非 .scene                  | `_buildWorld` 中提取 `propScenes[k] = g.scene`              |
| 5 | shells.update 未定义错误                            | 资产加载完成前进入帧循环                               | 添加守卫 `if (!this.paused && this.shells)`                  |
| 6 | **PAGEERROR: world.groundY 空引用（main.js:1060）** | 菜单状态下 ambientTimer 触发时 `this.world` 为 null | [main.js](../js/main.js) 烟柱分支添加 `&& this.world` 判空       |
| 7 | Effects groundY 回调同类隐患                         | 闭包捕获时 world 未创建                            | 回调改为 `this.world ? this.world.groundY(x,z) : 0`          |

缺陷 #6、#7 为最后一轮修复，修复后复跑全流程验证：**零错误通过**。

## 七、遗留事项与建议

1. **F5 小地图不更新废墟**（既有已知约束）：小地图底图为一次性预渲染，建筑摧毁后废墟不会反映在雷达上，属预期行为，如需更新可后续迭代。
2. **战斗内 AI 行为深度验证**：本次自动化脚本覆盖了 AI 敌坦存在与战斗循环无报错；AI 在小镇狭窄街道的寻路表现建议后续人工对局观察（可在战斗中观察 AI 是否卡建筑碰撞）。
3. **性能观察项**：小镇建筑群 + 阴影 + 粒子在低配设备的表现建议人工试玩确认（建筑已合批，见 8.2 节）。
