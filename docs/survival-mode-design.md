# 生存模式设计文档

## 1. 概述

生存模式是装甲前线的第三种游戏模式。玩家选择坦克后进入大地图，面对从四面八方涌来的敌方坦克波次进攻，在地图中央的维修据点进行防御和补给，坚持尽可能多的波次以获取高分和排名。

## 2. 菜单改造

当前主菜单仅一个「战争模式」按钮，改为三个模式入口：

| 菜单按钮 | 模式 | 状态 |
|---------|------|------|
| 决斗模式 | 当前 1v1 对战（改名） | 已有 |
| 战争模式 | 大规模对战（占位，后续设计） | 待定 |
| 生存模式 | 波次防御生存 | **本文档** |

### UI 改动

- `btn-war-mode` 文本改为「决斗模式」
- 新增 `btn-war-large-mode`「战争模式」（disabled，标注「即将推出」）
- 新增 `btn-survival-mode`「生存模式」
- 生存模式复用机库选车界面（`screen-hangar`），仅入口不同

## 3. 地图设计

### 尺寸与地形

- 地图尺寸：**3000m × 3000m**（比决斗模式 2200m 更大，给波次刷新留空间）
- 地形复用现有 `terrainHeight(x, z)` 噪声函数，但中央区域 **200m 半径内强制平整**（据点建筑需要平地）
- 散布物（岩石/树木/废墟）复用现有 `_scatter()` 逻辑，中央 200m 内不放

### 维修据点（地图正中央）

据点是一个可占领的圆形区域，半径 **40m**，包含：

- **建筑模型**：简易维修站（后续制作 3D 模型），含标识旗杆
- **占领机制**：
  - 玩家进入据点 40m 半径内开始占领，占领进度条 0→100%
  - 占领需 **5 秒**无敌方坦克在据点内
  - 若敌方坦克进入据点，占领进度暂停（不回退）
  - 占领成功后据点归属玩家，显示蓝色旗帜
- **维修功能**（占领后可用）：
  - 玩家在据点内静止（速度 < 1 m/s）时自动维修
  - 维修速率：**120 HP/秒**
  - 维修消耗：**荣誉点数**，每秒消耗 2 点
  - 荣誉点数不足时停止维修
  - 满血时自动停止

### 据点 HUD

- 占领进度条（屏幕下方居中，仅据点附近显示）
- 据点状态图标（己方蓝色/中立灰色/敌方红色）
- 维修中提示（HP 条闪烁 + 「维修中」文字）

## 4. 波次系统

### 波次规则

| 波次 | 敌方数量 | 备注 |
|------|---------|------|
| 1-5  | 2 台    | 热身阶段 |
| 6-10 | 3 台    | 压力提升 |
| 11+  | 4 台    | 高强度 |

### 波次流程

```
波次开始 → 从四方边界刷新敌方 → 玩家战斗 → 全部击毁 → 短暂休整(5秒) → 下一波
```

- **刷新位置**：从地图四个方向（北/南/东/西）的边界随机点刷新，距中心约 1400m
- **刷新方向分配**：敌方坦克均匀分配到四个方向，避免全从一个方向来
- **波次间隔**：每波之间 5 秒休整期，显示「第 N 波即将开始」倒计时
- **初始延迟**：第一波在玩家进入地图后 3 秒开始

### 敌方坦克

- 使用**特殊专用敌坦克**（后续制作，不在玩家可选列表中）
- 专用敌坦克配置独立于 `TANKS`，放在新的 `ENEMY_TANKS` 配置中
- 初期可复用现有坦克模型（如 T-80U），后续替换为专用模型
- 敌方坦克难度随波次递增：
  - 瞄准精度提升（误差系数随波次递减）
  - 开火犹豫冷却缩短
  - 装甲/血量可微调（可选）

## 5. 敌方 AI 行为

### 行为状态机

生存模式敌方 AI 在现有 `TankAI` 基础上扩展，增加 `patrol` 状态：

```
patrol（巡逻） → engage（交战） → patrol（巡逻）
```

### 巡逻逻辑（patrol 状态）

- **目标**：向地图中央据点移动
- **路线**：从刷新点沿一条预设巡逻路线向中心前进（非直线，带轻微偏移避免扎堆）
- **移动**：全油门沿巡逻路线前进
- **转交战条件**：
  - 发现玩家在 **500m** 内 → 切换到 `engage`
  - 到达据点 100m 内且据点未被己方占领 → 在据点附近待命防守

### 交战逻辑（engage 状态）

复用现有 `TankAI` 的交战逻辑（距离分级机动 + 瞄准 + 开火），但增加：

- **目标选择优先级**：
  1. 玩家坦克（若在射程内）
  2. 据点（若玩家不在附近，向据点移动占领）
- **据点占领行为**：若玩家不在据点附近，敌方进入据点 40m 内会尝试占领（占领进度对玩家逆向）

### 据点争夺

- 敌方坦克进入据点 40m 内时，玩家占领进度暂停
- 若据点已被玩家占领，敌方在据点内停留 **10 秒**可夺取据点
- 据点被夺取后玩家无法维修，需重新占领

## 6. 积分与排名系统

### 分数

| 事件 | 分数 |
|------|------|
| 击毁敌方坦克 | 100 × 波次系数 |
| 占领据点 | 50 |
| 维修（每秒） | 5 |

- 波次系数：第 N 波 = 1 + 0.1 × (N-1)，随波次递增

### 荣誉点数

| 事件 | 荣誉点数 |
|------|---------|
| 击毁敌方坦克 | 10 |
| 完成一波 | 20 |
| 维修消耗 | -2/秒 |

- 荣誉点数初始为 **50**，用于维修消耗
- 荣誉点数不可为负

### 排名

游戏结束后根据总分计算排名等级：

| 分数区间 | 等级 |
|---------|------|
| 0-500 | 新兵 |
| 500-1500 | 列兵 |
| 1500-3000 | 下士 |
| 3000-5000 | 中士 |
| 5000-8000 | 上士 |
| 8000-12000 | 军士长 |
| 12000+ | 尖尉 |

### 结算界面

- 生存波次：第 N 波
- 击毁数：X 辆
- 总分：XXXX
- 荣誉点数：XX
- 排名等级：XXXX
- 按钮：返回主菜单 / 再来一局

## 7. 玩家失败条件

- 玩家坦克被击毁（HP 归零 / 弹药殉爆）
- 失败后进入结算界面，显示分数和排名

### 新增/修改文件

| 文件 | 改动 | 说明 |
|------|------|------|
| `index.html` | 改 | 菜单按钮改名 + 新增按钮 + 据点 HUD 元素 |
| `css/style.css` | 改 | 据点 HUD 样式 + 波次提示样式 |
| `js/config.js` | 改 | 新增 `ENEMY_TANKS` 配置 + `SURVIVAL` 配置 |
| `js/main.js` | 改 | 状态机扩展 `survival` 模式分支 + `_startSurvival()` |
| `js/ui.js` | 改 | 据点 HUD 更新 + 波次提示 + 生存结算 |
| `js/ai.js` | 改 | 新增 `patrol` 状态 + 据点争夺逻辑 |
| `js/survival.js` | **新建** | 生存模式管理器（波次/据点/积分） |
| `js/capture-point.js` | **新建** | 据点占领逻辑（可选，也可内联到 survival.js） |

### 状态机扩展

```
loading → cover → menu → hangar → survival → result
                                   ↘ battle → result  （决斗模式）
```

- `main.js` 新增 `this.state = 'survival'` 分支
- `_startSurvival()` 类似 `_startBattle()`，但调用 `SurvivalManager` 管理波次
- `_frame()` 中 `survival` 分支调用 `survivalManager.update(dt)`

### SurvivalManager 核心接口

```js
class SurvivalManager {
  constructor(scene, world, player, enemies, ais, effects, audio, ui)
  start()                    // 开始生存模式（第一波延迟 3s）
  update(dt)                 // 每帧更新：波次/据点/积分/AI
  spawnWave(n)               // 刷新第 n 波敌方
  onEnemyKilled(enemy)       // 敌方被击毁回调
  onPlayerDestroyed()        // 玩家被击毁回调
  dispose()                  // 清理
}
```

### 据点实现

- 据点用 `THREE.Group` 包含建筑模型 + 旗杆
- 占领进度用 0~1 浮点数，每帧根据据点内坦克归属更新
- 占领判定：遍历所有坦克，检查到据点中心距离 < 40m
- 维修：玩家在据点内且速度 < 1 m/s 时，`player.hp += 120 * dt`，`honor -= 2 * dt`

### 波次刷新

```js
spawnWave(n) {
  const count = n <= 5 ? 2 : n <= 10 ? 3 : 4;
  const dirs = ['N', 'S', 'E', 'W'];
  for (let i = 0; i < count; i++) {
    const dir = dirs[i % 4];
    const pos = this._spawnPos(dir);  // 对应方向边界随机点
    const cfg = this._pickEnemyTank(n);
    const enemy = new Tank(cfg, clone, this.world);
    enemy.place(pos.x, pos.z, faceCenter);
    this.enemies.push(enemy);
    this.ais.push(new SurvivalAI(enemy, this));  // 带 patrol 状态
  }
}
```

### AI 扩展

`SurvivalAI` 继承或包装 `TankAI`，增加：

```js
class SurvivalAI extends TankAI {
  constructor(tank, survivalManager)
  update(dt) {
    // patrol 状态：沿巡逻路线向中心移动
    // 检测玩家距离 < 500m → engage
    // engage 状态：调用 super.update(dt)
  }
}
```

### 地图调整

- 生存模式地图 3000m，需在 `World` 构造时传入尺寸参数
- 或复用 2200m 地图但调整出生点和刷新点（更简单，改动更小）
- 中央 200m 平整区可在 `terrainHeight` 中加生存模式标记
