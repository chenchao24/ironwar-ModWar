## 一、热成像瞄具（新系统）

### 1.1 功能概述

为装备热像仪的坦克提供狙击镜 IR 模式：白热调色画面 + 分级热源 + 穿透烟雾锁定目标，形成装备代差玩法。

### 1.2 技术实现

| 环节         | 方案                                                                 |
| ---------- | ------------------------------------------------------------------ |
| 热值注入       | `material.onBeforeCompile` 向 MeshStandardMaterial 片元注入热值 uniform，IR 开启时跳过光照直出灰度 |
| 渲染管线       | 条件双 pass：scene → 0.5× RenderTarget → 全屏 quad（白热调色 / 噪点 / 扫描线 / 渐晕）；高倍变焦（>4×）RT 升 0.75× 防颗粒 |
| 性能         | IR 仅开镜时激活；期间停阴影更新省开销                                             |
| 粒子适配       | 烟粒子=冷灰遮热、火焰/炮口焰=白热                                               |
| 穿烟规则       | IR 观察者完全豁免烟雾遮挡判定（无距离限制）                                          |

### 1.3 装备门槛（按真实装备分级）

| 有热像（N 键可用）                        | 无热像                      |
| ---------------------------------- | ------------------------- |
| 豹 2A7 / M1A2 SEPv3 / 挑战者 3 / 艾布拉姆斯X / T-14 / ZTZ-99A | T-90M / T-80U / T-90SM / M1A1SA / 豹 2A4 |

AI 敌坦暂不对等享受热像穿烟（v1 仅玩家，避免难度突增）。

### 1.4 操作与 UI

- **N 键**：镜内开/关 IR（关镜自动关闭）；无热像车无效
- 狙击镜读数区 IR 琥珀指示灯；机库性能参数表新增「热成像」条目

### 1.5 新增文件

- `js/thermal.js`（核心模块，约 300 行）
- `scripts/verify_thermal.mjs`（10 项自动化验证）

## 二、炮长镜与开镜操作（交互重做）

### 2.1 瞄准镜视觉

- 基础 FoV 26°→**32°**：开镜默认放大 ×2.4→×1.9，视野更宽
- 黑色遮罩硬边改为**全屏径向羽化渐变**（中心 66% 清晰 → 边缘无级渐黑），模拟真实镜片虚化
- 变倍上限 8×→**12×**（容纳真实炮长镜高档位）

### 2.2 炮长镜物理 2 档（按真实瞄具定档）

| 坦克                                  | 档位          | 真实瞄具               |
| ----------------------------------- | ----------- | ------------------- |
| T-90M / T-80U / T-90SM / T-14       | **4× / 12×** | 1A40-4 / 1A43 / Sosna-U |
| 豹 2A7 / 豹 2A4                      | **2× / 8×**  | PERI-R12A3 / EMES-15 |
| M1A1 SA / M1A2 / AbramsX / ZTZ-99A  | **3× / 10×** | Raytheon / GPS / 上反稳 |
| 挑战者 3                               | **3.5× / 12×** | Sapphire            |

### 2.3 新操作语义

| 操作             | 功能                                   |
| -------------- | ------------------------------------ |
| **Shift 点击**   | 开镜 / 关镜（闩锁式，左右 Shift 均可，不用一直按住）     |
| **右键点击（镜内）**  | 炮长镜 2 档循环（如 4×↔12×），按对数最近档衔接          |
| 右键（镜外）        | 无功能（右键开镜已移除，专职切档）                    |
| 滚轮             | 自由变倍不变（可与档位无缝混用）                     |
| 暂停 / 退出战斗      | 开镜闩锁自动复位                             |

### 2.4 命中率调优（散布体系）

问题：满缩圈散布按角度线性放大，300m 外命中骤降、500m+ 几乎打不中。

| 项             | 调整前          | 调整后         |
| ------------- | ------------ | ----------- |
| 满缩圈散布（11 车）  | 0.0025~0.0034 rad | **0.0013~0.0018 rad** |
| 开火后扩圈       | 5×           | **3×**      |
| 移动扩圈 / 转塔惩罚 / 观瞄损伤 / aimTime | 保持不变（交战节奏不变） | 同左          |

实测（静对静、禁 APS、20 发 AP、T-90M）：300m **100%** / 500m **95%** / 800m **50%**（长距衰减故意保留）。

## 三、性能优化

### 3.1 落地项

| 项                | 内容                                                         | 收益                          |
| ---------------- | ---------------------------------------------------------- | --------------------------- |
| A1 地面分段         | 小镇 480→200 / 平原 440→200（25m/格）                            | 三角形 -38 万/帧               |
| A2 dpr 降档        | high 2→1.5 / medium 1.5→1.25                               | 高分屏像素成本 -44%              |
| A4 距离剔除          | 布景 >1100m 隐藏（0.5s 节流）+ 雾收近（小镇 1800→1300m）                 | 视野边缘 draw calls 约 -25%     |
| B1 建筑合批          | 194 栋 → 74 个 InstancedMesh（≥12 实例的流按象限切分保视锥剔除）             | **draw calls 456→150~270**  |
| 开镜 overdraw 修复   | 点精灵屏幕尺寸钳制 0.45×视口高（uMaxPx）                                 | 开镜各状态帧数持平（24/24/24/23）     |
| FPS 监控           | 右上角黑底白字 11px，0.5s 滚动均值                                    | 实机调优可观测                    |

### 3.2 建筑合批的受损抽出机制（关键设计）

**完好建筑走合批（1 draw call），挨打瞬间退出合批**：

- 首次炮击命中 / 终击倒塌 / 履带压毁 → 该栋实例矩阵置零 + 挂回预构建独立克隆
- 之后完全走既有灰化/倒塌/压扁管线（原代码零改动）
- 灰化材质克隆只作用于抽出克隆，其余实例共享材质不受污染
- 备份在 `backup_b1/`，可整体回退

### 3.3 已回退项（视觉优先决策）

- **B2 阴影节流**（每 2.5m 重绘）与纹素吸附：实测阴影抽动/穿帮，两轮修复未达预期 → **整体回退**为原版（2048 贴图 / 90m 覆盖盒 / 每帧自动更新）。教训：阴影视觉正确性优先于节流收益。
