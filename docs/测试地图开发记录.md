## 一、定位与架构

### 1.1 设计目标

- 2000×2000 东欧战区小镇，十字公路穿过，仅放玩家坦克

- **与游戏正式内容完全隔离**（独立页面，不污染 main.js / 正式地图）

- **玩家操作、视角、手感与正式游戏 100% 一致**——未来直接用于游戏

### 1.2 与正式游戏的一致性（复用正式模块）

复用 `Tank` / `CameraRig` / `Input` / `ShellManager` / `TrackMarks` / `ParticleSystem` / `Effects` / `audio`，逐行对照 main.js 战斗循环补齐：

| 项目               | 说明                                      |
| ---------------- | --------------------------------------- |
| G 键烟雾弹           | SmokeManager，4 发弹体、2s 冷却、3 次弹药，HUD 显示余量 |
| 开炮抛壳             | 炮塔顶部靠后抛壳，延迟 0.8-1.2s（与 main.js 同参）      |
| 狙击镜白闪            | 镜内开火 0.18s 白闪（复刻 ui.js scopeFlash）      |
| 镜内散布虚线圈          | 按当前散布 × 变倍换算直径，随缩圈实时收缩                  |
| 瞄准缩圈进度           | "缩圈 X% / 已瞄准"，aimFrac ≥ 0.985 准星变绿      |
| 粒子 FoV 同步 + 远景烟柱 | 变倍时粒子保持世界尺寸；战场四周氛围烟柱                    |

操作方式与游戏一致：W/S/A/D 驾驶、鼠标观瞄、RMB/SHIFT 狙击镜、滚轮变倍、LMB 开火、F 机枪、G 烟雾弹、1/2/3 弹种、R 维修、T 灭火、C 观赏视角、ESC 暂停。

## 三、小镇布局设计（三轮迭代）

### 3.1 第一版：完全随机散布（被否决）

房屋零散撒在地图上，用户反馈：**过于零散、不合理**。

### 3.2 第二版：院落式布局

新增 `household()` 生成器——一家一户设计，非随机摆放：

**每户统一结构、细节各异：**

- 临街主屋（门朝公路，长轴沿街）+ 木围栏院落（前栏留 10m 大门，30×38m 地块）

- 院内：棚屋（38%）、柴堆（60%）、配电箱（70%）、长椅（22%）、拖车（12%）

- 绿化：院内 1-2 棵树 + 临街行道树

**分区结构（70% 集中 / 30% 零散）：**

| 分区     | 内容                                  |
| ------ | ----------------------------------- |
| 十字主街   | 40 个地块（48m 间距）沿公路两侧排布，约 28 户 + 绿地间隔 |
| 西南老城   | 8 户小地块密集小巷                          |
| 东北庄园   | 大宅 + 花园围墙 + 园林树                     |
| 西北集体农庄 | 谷仓群 + 青储塔 + 拖车（围栏圈起）                |
| 东南工业堆场 | 办公室 + 集装箱 + 发电机（围墙圈起）               |
| 外围零散   | 9 户农舍沿公路四臂分布（430-690m）              |

**树木分布**：镇内点缀（院内树 40% 概率、尺寸偏小 0.4-0.75），镇外 16 处林簇（每簇 11-17 棵，leaf 冠幅 6-16m / pine 5-9m）。

## 四、可破坏物件系统

### 4.1 标注驱动开发

用户通过 `docs/小镇物件标注表.md` 逐项标注：碰撞（有/无）、可炮毁（是/否）、炮毁残骸高度、可压毁（是/否）、压毁残骸高度。系统按标注实现，规则表：

- `PROP_RULES`：group 物件（建筑/车辆/集装箱等）

- `INST_PROPS`：Instanced 物件（围栏/树木/岩石/柴堆）

- `COLLAPSE_TYPES` 白名单：只有 A 组建筑（house01/02/03、barn01/03、barrack01-04）走完整倒塌流程，其余物件一般性毁坏（小爆 + 碎片 + 压扁残骸，无倒塌烟雾/废墟堆）

详细效果参数见 `docs/A组建筑效果表.md`。

### 4.2 弹种规则

| 弹种        | A 组建筑                                              | 其他物件       |
| --------- | -------------------------------------------------- | ---------- |
| HE 高爆     | 正常扣血 → 灰化 → 终击倒塌                                   | 正常摧毁       |
| AP / HEAT | **只有效果**（包围烟 + 少量木屑 + 爆响），不扣承受数、不灰化、不倒塌；炮弹仍被墙体拦截爆炸 | 正常摧毁，不区分弹种 |

### 4.3 命中交互分类

| 物件               | 炮弹           | 履带                   |
| ---------------- | ------------ | -------------------- |
| A 组建筑            | 拦截爆炸 + 按弹种扣血 | 阻挡（实心碰撞）             |
| 一般物件（卡车/集装箱/水塔等） | 拦截爆炸 + 摧毁    | 压毁（压扁残骸）             |
| **围栏**           | **穿过**（不可炮击） | 压毁（碎屑）               |
| **电线杆**          | **穿过**（不可炮击） | **压倒**（绕根部倒伏，与树同款动画） |
| 树木               | 拦截爆炸 → 倒伏    | 压倒（倒伏）               |
| 岩石               | 拦截爆炸         | 不可压毁，阻挡              |

### 4.4 压毁阻力分级（碰撞感）

碾过瞬间按等级减速 + 相机震动 + 撞击音量加重：

| 等级 | 速度衰减  | 震动   | 音量   | 物件                      |
| -- | ----- | ---- | ---- | ----------------------- |
| 轻质 | ×0.90 | 0.12 | 0.20 | 围栏、柴堆、金属板、长椅、路牌、电缆盘、配电箱 |
| 中质 | ×0.70 | 0.28 | 0.30 | 卡车、拖车、水塔、发电机、集装箱        |
| 重质 | ×0.55 | 0.37 | 0.38 | 树木、电线杆                  |

## 五、建筑摧毁效果（多轮调试的最终形态）

### 5.1 迭代史（每轮用户反馈 → 修正）

1. **v1 简单下沉**：炮击逐次压低建筑高度 → 用户否决："不是想要的效果"
2. **v2 完整流程**：命中着火 + 灰化 → 终击坍塌下沉 + 废墟堆 → 用户细化要求
3. **v3 去火加烟**：命中不着火，大量灰/灰褐/土色多层烟包围房屋；终击 1 秒内爆烟覆盖 2-3 倍房屋面积；下沉 3-4s 前慢后快；废墟中途出现、扩 1.3 倍、多灰度、悬浮 1m 烟 10-20s
4. **v4 去废墟火**：废墟持续烟尘移除，仅 12% 几率残留少量明火；命中烟尘加大加乱（随机角度、命中侧集中）
5. **v5 烟位置修正**：烟雾改到建筑**外侧**（原在中心被楼体遮蔽）——弹着点主烟柱沿"中心→命中点"外推 3-6m，环绕烟罩改为椭圆轮廓外一圈且 80% 集中命中侧扇区
6. **v6 碎片形态修正**：纷飞的"水泥块"不符合实际——建筑主要是木头，改**长条木片为主 + 少量小砖石**（砖块尺寸 ×0.55）；围栏/柴堆/树纯木片
7. **v7 烟雾按房屋尺寸**：固定烟径改为按跨度生成（初始 ×1.5，膨胀 ×2-3，数量按占地系数）
8. **v8 碎片量 ×3-5**：基础碎片 ×3、终击 ×5，大块近处掉落（低速）/小块飞很远（高速），爆炸范围 2 倍房屋（多点抛射）；碎片池 40 → 200
9. **v9 弹种限制**：AP/HEAT 对建筑只有效果不扣血
10. **v10 倒塌方式修正**：≥2 发击毁的建筑从纯沉降改为**倾斜沉降式**——随机倒塌方向，倒塌侧沉降 100%、对侧 30%，边降边斜（k^2.3 缓动，以低沉降侧边缘为 pivot）；终态不移除模型（30% 侧约 70% 墙体斜插地面）；废墟偏移到完全沉降侧（0.8×半跨）避免被墙体覆盖

### 5.2 最终效果参数

**命中阶段**（不下沉、不着火）：

- 材质灰化（水泥灰 + 泥土色，每次 30%）

- 弹着点 3 股粗大烟柱（终径 22-34m）在墙体**外侧**

- 环绕烟罩 14-20 团（灰白/灰/灰褐/土色四层，随机角度外扩 0.9 倍房宽，80% 集中命中侧）

- 木屑 9-14 片（长条 0.55×0.035×0.12m 几何）

**终击倒塌**（3.2-4s）：

- 瞬间爆烟 52-66 团（按占地：house03 \~24-29 / house01 \~52-62 / house02 \~84-109），烟径=跨度×1.5 起膨胀至 ×2-3，覆盖 2-3 倍房屋面积，1 秒内达到最高浓度

- 下沉曲线 k^2.3 前慢后快；期间每 60ms 补 3 团尘云

- 碎片爆发：240 木片 + 30 砖石 × 占地系数，大块（35%）低速近落 / 小块高速远飞，多点抛射覆盖 2 倍房屋

- 废墟在下沉 38% 时从地面 smoothstep 升起，范围扩 1.3 倍（house02 ×2）

- 废墟配色：低饱和 6 色（深灰 #565650 / 暗灰 #63625c / 土褐 #6e6558 / 褐灰 #5c5348 / 灰褐 #716b60 / 深褐 #4a463f）+ 木梁 + 碎木板

- 废墟仅 12% 几率 1-2 处少量明火（10-16s 自熄）

**地形残留**：废墟高度场叠加余弦坡度（坦克骑上去有起伏）；残骸 ≥1.5m（house01/02）保留阻挡（半径缩至 55%）。

## 六、树木与落叶

### 6.1 倒伏机制（两轮修正）

- v1 压扁成饼 → 改**绕根部倒下**（0.85s 加速倒伏 \~81°，朝远离坦克方向）

- 炮击毁树同样倒伏（不再留树桩）

- 落地扬尘 + 木屑 + 树冠/树根持续烟尘（8-10s → 后缩至 **3-4s**）

### 6.2 落叶飞散系统（三轮修正）

1. v1 复用木片几何 → 太大
2. v2 专用叶片 5×3cm → 太小看不见、上扬太慢
3. **最终**：叶片 **7.5×4.5cm**（±25% 微差），炮击 45-65 片 / 落地 68-96 片 + 树干中段 24-40 片

   - 起点在**树冠外侧环形**（方位角全随机 + 半径 0.8-1.3 倍冠幅，冠幅按树缩放 ×2.5 估算）

   - 初速 12-18 快速炸起 → 重力 2.6 加速飘落，**约 2-3s 全部落地**

   - 1/4 数量灰土碎屑与叶子混飘（尘叶混合）

   - 配色：阔叶橄榄绿 4 档 / 松树深绿松针 3 档

## 七、天空 / 雾 / 光照（多轮迭代）

### 7.1 天空云（四轮迭代，最终采用 darkWil 柏林关方案）

1. canvas 程序化云贴图（90 积云簇）→ 太多不自然
2. 减半 + 体积感修正 → 边缘破碎度不够，"不像"
3. 移植 darkWil clouds.js 高斯羽化纹理 → 效果仍差
4. **最终**：darkWil environment.js 的**着色器三层 fbm 噪声云**，并按**柏林关（level\_04\_berlin）参数**配置：

   - coverage 0.55 / color 0xf4f6f8 / highlight 0xf8f4e8 / farDarken 1.0 / drift 0.005 / zenithBoost 0.5

   - 三层：远景层云带（地平线，水平拉伸 3.5 倍）/ 中空层积云 / 高空天顶卷云

   - **天顶 3D 噪声采样**（fbm3(dir)）——2D 采样在天顶会径向拉抻出放射条纹，这是早期效果差的根源

   - fbm 5 层倍频 + 旋转矩阵 36.87° 打破网格对齐；云受太阳方向光照

   - 零 draw call、无穷远、无接缝

   - **接缝白线修复**：v1 用 atan(vDir.z, vDir.x) 计算经度有 π→-π 分支跳变产生亮线，改为球体自带 UV 采样（后随 fbm 方案该问题自然消失）

### 7.2 距离雾（三轮调浓）

线性 Fog `#c8d8e4`：

- v1 `350-3600m` → 用户反馈"不明显"

- v2 `120-3200m` → 仍不明显

- **最终** **`80-1800m`**：500m 24% / 1000m 53% / 1414m 78% / 1800m+ 100% 融进雾色；近处清澈不影响战斗；雾色与天空地平线色一致

### 7.3 光照（晴天 → 午后氛围）
