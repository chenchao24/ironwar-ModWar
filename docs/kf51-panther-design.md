## 三、迷彩涂装方案（重点）

### 3.1 技术路线：运行时程序化迷彩（推荐 ✅）

游戏现有贴图全部为 CanvasTexture 程序化生成（粒子/地面/履带印），迷彩沿用同一哲学：

- **不改 GLB 文件**：tank.js 材质克隆后，为 KF51 的车体/炮塔/炮管材质挂上运行时生成的迷彩 CanvasTexture
- **一张 1024×1024 可平铺迷彩块**：模型 UV 主体是 U[0,1]×V[-1,0] 整块平铺（§1.1），`RepeatWrapping` 直接采样（V 负值自动回卷、裙板件 U×4 自然重复）；迷彩斑块用周期化绘制（越界补画 ±1 纹理周期间拷贝）保证无缝平铺
- **材质参数修正**：metal 1.0→**0.2**、rough 1.0→**0.85**（漆面钢装甲，消除白陶土感）
- **触发方式**：config 增加 `camo: 'kf51'` 标记，`tank.js` 构建时按标记调用 `applyCamo(model, scheme)`（新增 `js/camo.js`，~120行，纯 Canvas 2D）
- **可逆/可扩展**：不碰模型文件；后续给勒克莱尔/10式/梅卡瓦换 scheme 一行配置

### 3.2 涂装样式（依据实车照片）

莱茵金属 2022 展示车（Eurosatory/DSEI 实拍）为**三色角状碎裂迷彩**：

| 色块 | 参考色 | 占比 |
|---|---|---|
| 底色 | 沙黄 #B9A77C | ~55% |
| 斑块1 | 深橄榄绿 #566044 | ~25% |
| 斑块2 | 红棕 #6F523C | ~20% |

附加做旧细节（叠加在迷彩上）：
- 细面板缝线（深色 8% 透明度细线，横纵随机）
- 垂直尘土流挂（车体下半部、履带上方，半透明土色长条）
- 轻微噪点颗粒（整体质感）
- 履带（Object_16/4）不上迷彩：纯深灰黑 #35342F 橡胶感

### 3.3 生成参数（实现约定）

- 种子随机固定 → 每次进入车库/战斗涂装一致（不闪变）
- 斑块：45±15 个多边形，锐利折线边（角状碎裂感，非圆斑），两档尺寸（大 180~320px / 小 60~120px）
- 边缘处理：斑块边缘 1px 深色描边模拟喷涂边界
- 分辨率 1024²，浏览器端一次性生成 ~10ms，无性能影响

### 3.4 验收方式

车库展示 + 战斗第三人称 + 瞄准镜 + 热像四视角截图，交视觉评审核对：迷彩可见度、平铺无明显接缝/镜像感、烧毁变色仍生效（材质 color 乘法叠加）。

### 3.5 后续可选扩展（本次不做）

勒克莱尔（法四色）、10式（日本双色丛林）、梅卡瓦（西奈灰）复用同一系统各配一个 scheme——如需要另行立项。

## 六、风险

| 风险 | 对策 |
|---|---|
| UV 平铺导致迷彩在相邻部件呈现相似纹理走向 | 迷彩本身随机斑块，视觉可接受；验收截图确认，不行则改为“按部件 hash 偏移 UV 采样偏移”二次调整 |
| 白模→迷彩后车库曝光偏差 | 色板亮度与 M1 沙黄/T-90M 墨绿之间，车库已按两者校准；截图复测 |
| Object_17 车顶件做机枪网格可能偏大（1.6m 宽组件） | mgGroup 旋转轴自动取组件位置；视觉若突兀改用虚拟枪口（一行配置） |
| 伤害 470/穿深 760 对现有 14 车平衡冲击 | 全场第一但无任何主动防护；实战胜负局实测后再调 |
