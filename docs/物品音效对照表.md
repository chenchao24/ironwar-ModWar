## 三、实现说明

- **加载**：`audio.js` 在用户手势 `init()` 后 `loadPropSounds()` 并行解码 10 个 MP3（约 660KB，实测 ~100ms）；走 `sfxGain` 通道（受「音效」滑杆控制）。
- **播放接口**：`audio.playProp(name, vol)` —— name 为 `collapseLg / collapseSm / houseHit / treeTopple / treeCreak / treeShot / crushObj / ramHouse / crushWood / crushRubble`。
- **去重**：同名音效 120ms 内不重复播放（压毁与碰撞同帧双触发、一次碾过多段栅栏时只响一声）。
- **距离衰减**：物件音以玩家坦克为听者（`destructibles.listener`），远处音量按 `1 - dist/800×0.8` 衰减；碾毁音按坦克与物件距离 /500 衰减。
- **倒树归属规则（2026-09-03 调优）**：炮击倒树（tree_shot_fall）不分归属走标准衰减；**压倒**区分——玩家压倒全额（主音 0.54），敌坦压倒受 50m 静音门（`_enemyTreeGate`：50m 外无声，50m 内 `1 - d/50` 线性衰减），主音/吱嘎/落地全程一致。实测（`scripts/probe_tree_vol.mjs`）：玩家 8m→0.536、敌坦 20m→0.318、45m→0.052、100m→静音、玩家 60m→0.508。
- **音效文件缺失时静默跳过**（不回退程序合成音），加载失败仅 console.warn。
- **验证脚本**：`scripts/verify_props_sounds.mjs`（解码 10 项 + 11 组触发断言），配合 `node server.js` 运行。

## 四、调参入口（改哪里）

| 想调什么 | 位置 |
| --- | --- |
| 大/小房屋倒塌音分界（当前 80㎡） | `destructibles.js startCollapse()` 的 `w * dp >= 80` |
| 敌坦压倒树的静音距离（当前 50m，50m 内线性衰减到 0） | `destructibles.js _enemyTreeGate()` |
| 玩家压倒树主音量（当前 0.54） | `destructibles.js fellTree()` 的 `(shot ? 0.9 : 0.54)` |
| 撞击房屋触发灵敏度（当前速度 >0.8、位移缩水 >40%） | `tank.js drive()` 的 `_ramHit` 判定 |
| 撞击音冷却（0.5s）/ 碾废墟音间隔（1.1~1.8s） | `tank.js update()` 物件音效段 |
| 倒树吱嘎声次数（当前 2 次：0.22s / 0.5s） | `destructibles.js updateFallingTrees()` 的 `creaked` 逻辑 |
| 各场景音量 | `destructibles.js` / `tank.js` 中 `playProp(...)` 第二参数 |
| 同名去重窗口（120ms） | `audio.js playProp()` |

## 五、遗留说明

- **「碾过已倒树木」**：游戏中树倒下后不再是障碍物（坦克直接驶过），该场景无物理事件；`crush_wood.mp3` 已用于木栅栏/柴堆碾压与树倒落地冲击，两者音色一致。若需要"倒树变矮障碍、碾过发声"需后续加碰撞逻辑。
- **AI 敌坦**同样触发全部物件音效（碾毁/撞房屋/碾废墟均以玩家为听者做距离衰减）。
