# A 组建筑效果表（倒塌系统）

> 适用范围：**仅 A 组建筑**使用倒塌系统（灰化 → 包围烟 → 终击倒塌 → 程序化废墟）。
> 其余全部物件（车辆 / 集装箱 / 水塔 / 发电机 / 围栏 / 树木 / 电线杆 / 小品等）为**一般性毁坏**：小型爆炸 + 碎片 + 压扁残骸，无倒塌烟雾。
> 弹种规则：A 组建筑**只有 HE 高爆弹**能摧毁结构；AP / HEAT 命中只有烟尘与碎屑效果，不扣承受数。其余物件不区分弹种。

## 二、各阶段效果明细（A 组通用流程）

| 效果     | 参数                                       |

| 全屋烟罩   | 14 团（终击 20 团），80% 集中命中侧，轮廓外不规则分布         |
