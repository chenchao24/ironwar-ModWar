## 一、模型分析结论（已实测验证）

用 gltf-transform 世界空间解析 + 浏览器内 three.js 渲染测量，并与豹2A7（`+z`）/挑战者3（`+x`）两个参考模型比对：

| 模型 | 炮口实测位置（世界系） | 朝向结论 | 与用户描述一致 |
|---|---|---|---|
| leclerc_s2.glb | 炮管沿 **+Z**，炮口 Z=6.48，炮轴线 Y≈1.91 | `forwardAxis: '+z'`（与豹2A7 同，无烘焙） | ✅ |
| merkava_mark_iv.glb | 炮管沿 **+X**，炮口 X=4.11，炮轴线 Y≈2.05 | `forwardAxis: '+x'`（与挑战者3 同，Y-90° 烘焙） | ✅ |
| type_10.glb | 炮管沿 **+Z**，炮口 Z=5.53，炮轴线 Y≈1.84 | `forwardAxis: '+z'`（与豹2A7 同，无烘焙） | ✅ |

### 1.1 尺寸校准（三模型均约 1:1 米制，scale = 1.0）

| | 车体长（模型实测） | 车宽（含裙板） | 炮塔顶 | 判定 |
|---|---|---|---|---|
| 勒克莱尔 | 6.76m（实车 6.88） | 3.52m（实车 3.71） | ~2.55m | scale 1.0 |
| 梅卡瓦 | 7.50m（实车 7.60） | 4.29m（实车 3.70，模型裙板偏宽） | ~2.77m | scale 1.0 |
| 10式 | 7.40m（实车 ~7.4） | 3.34m（实车 3.24） | ~2.87m（含观瞄桅杆） | scale 1.0 |

三车履带底 Y≈0，无需 modelYOffset。

### 1.2 异常部件（需隐藏）

两个模型各有一块**非真车部件**的竖立薄板（同一 Sketchfab 导出管线产物），已视觉+几何双重确认：

- **勒克莱尔 Object_18**：2.1×2.6m、厚 3cm，立于炮塔尾部，顶高 5.07m——超出炮塔顶 2m，是全车最高点
- **10式 Object_30**：2.6×1.8m、厚 2.3cm，同位置，顶高 4.26m——超出炮塔顶 1.13m

处理：加入 `parts.hidden`（勒克莱尔 md 标注本就要求隐藏 Object_20 尾篮；Object_18/30 一并隐藏）。梅卡瓦无此问题（高耸件为真实天线）。

### 1.3 梅卡瓦负重轮特殊处理

每个轮节点为**左右两侧合并**的横跨全宽网格（8 个节点：6 对负重轮+前诱导轮+后主动轮）。`tank.js` 的轮组旋转绕节点中心 X 轴——若旋转会导致车轮绕车体中线甩动。因此 **`wheelsRotate: false`**（与 T-90M/豹2A7/99A 一致，履带 UV 滚动不受影响）。

## 四、可选顺手修复项（请审核勾选）

### 4.1 豹2A7 炮口/pivot 校准（推荐 ✅）

实测发现现有配置与 8-31 重导出的新模型不匹配：**炮弹出生点在 Y=0.48（车体下缘），而视觉炮管在 Y=1.97**——豹2A7 开炮弹道从炮管下方 1.5m 处发出。其余 10 车均正常（此为唯一不一致项）。修复：

```
turretPivot  [0, 0.184, -0.194] → [0, 1.70, -0.194]
barrelPivot  [0, 0.45, 1.2]    → [0, 1.97, 1.2]
muzzleLocal  [0, 0.48, 6.5]    → [0, 1.97, 7.03]
```

（挑战者3 的 muzzle Y=1.45 vs 实测炮轴 1.92、炮口 Z=7 vs 实测 6.36，偏差 ≤0.5m，属"模板值"水平，与 M1 系一致，可不动。）

本次新建了 `newTankmodel2-preview.html`（模型预览/视角切换调试页，含 DRACO 支持），建议保留作后续新车型接入的核查工具；分析脚本已归档至 `scripts/analyze_new_tanks.js` 等。

## 六、风险与对策

| 风险 | 对策 |
