### 1.3 材质转换（重要）

strv/2RI 为 War Thunder OBJ 转换导出，材质为 `KHR_materials_pbrSpecularGlossiness`——
three 0.185 的 GLTFLoader 已移除该扩展支持 → **渲染白模**。处理：

```bash
gltf-transform metalrough model_bk/<车>.glb.orig model/<车>.glb   # spec-gloss → metalRough
gltf-transform draco model/<车>.glb model/<车>.glb                # 再压缩
```

转换后自带迷彩贴图完整保留（strv=瑞典 M90、2RI=印尼绿），**无需程序化迷彩**（用户已确认）。
main.js 的 `GLTFPBRSpecGlossExt` 插件仍保留，兼容旧 spec-gloss 资产。压缩后体积：
strv 26.8→17.6MB、2RI 22.8→12.7MB、t-72b3 8.8→7.9MB、challenger_2 7.2→6.0MB。

### 1.4 车顶机枪与单位 TRS 节点（tank.js 修复）

WT 系导出（strv/2RI/挑战者2/T-72B3，含既有 type_10）所有网格节点 TRS 为单位阵（几何烘焙在世界坐标），
`tank.js` 机枪伺服支点原取「第一件机枪网格的节点原点」= **模型原点（地面车底）**，
mgYaw 伺服会使机枪绕车体原点甩动。修复（`tank.js _splitParts`，两级约定）：

> **支点兜底**：节点原点不在机枪包围盒内时，用**首件机枪网格（config 约定列为枪架/支座件）
> 的包围盒底面中心**作为枪架回转中心。注意不能用整组包围盒中心——那会落在枪管中段，
> 旋转时整枪甩出炮塔（T-72B3 实测踩坑）。节点原点在包围盒内的旧车（T-80U/M1 系等）行为不变。

**T-72B3 特例（mgFlipY）**：车顶 NSVT 出厂朝后收纳（枪管 z[-2.37,-1.0]）。`mgFlipY: true` 时：
- 机枪网格照常进 mg 伺服组，构建时记录 `mgBaseYaw = π`；
- 伺服应用 `rotation.y = mgYaw + mgBaseYaw`（视觉朝前），枪口包围盒推导取 -Z 端；
- 无瞄准点方向的曳光轴用 `(0,0,mgFlip)`（-1）。
支点 = mount3（枪架件）包围盒底面中心 → 模型系 (-0.73, 2.42, -0.97)，翻转后枪口几何位于
(-0.79, 2.79, +0.43)（炮塔顶左前，朝天越过舱盖，实车同款战斗朝向）。

**游戏内实测**：炮塔旋转时 NSVT 随动 ✓；伺服 ±150° 扫描 rotation = mgYaw + π 全对 ✓；
枪架原地不动、枪身绕支座摆动 ✓；AUTO 机枪实战射击正常（2RI）。

### 1.5 内部件染色（interiorTint）

T-72B3 的内衬件（炮塔篮圈 internal001 / 车体内衬 interior-hull / 炮体内 internal）贴图本身为白色，
从车长/装填手舱口与炮塔缝透视时呈白色穿帮。`tank.js` 支持 `cfg.interiorTint`：材质克隆后按
名字含 `interior|internal` 的网格把 `material.color` 染成指定色（与贴图相乘）。
t-72b3 取 `'#57614a'`（车体同系橄榄绿），机库/战斗实测白色穿帮消失。其他车如出现同类穿帮，
在 config 对应坦克加一行 `interiorTint` 即可。
